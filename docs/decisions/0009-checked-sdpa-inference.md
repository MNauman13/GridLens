# ADR 0009: optional checked SDPA inference

Accepted for I2, 25 November 2026.

Keep the original attention, Transformer, numeric forecasting, TimeXer, training and bundle modules byte-for-byte unchanged. Construct an independent eval-mode model copy and replace only its multi-head attention modules. Preserve projection parameters and state-dict names exactly. A different execution engine gets a separate runtime identity; it does not get a new trained-model identity. Teacher forcing, KV caching, retraining, quantisation and architecture changes are outside I2.

The adapter uses PyTorch functional scaled dot-product attention with automatic backend selection. GridLens masks still mean True=blocked; invert them at the SDPA boundary. Explicitly pass dropout_p=0 even when the module is in eval mode. Fully blocked queries remain errors. Attention weights are absent by default; an explicit inspection request uses the original manual operator. There is no silent runtime fallback on an SDPA execution error. See the official [PyTorch 2.14 SDPA contract](https://docs.pytorch.org/docs/2.14/generated/torch.nn.functional.scaled_dot_product_attention.html).

Retain shape, finite projected Q/K/V, mask and finite-score validation. The first measured candidate repeated the entire score matmul as an overflow preflight and regressed on both architectures. Its source, report, predictions and all timing samples are retained under reports/i2/preflight-trial. This rejected attempt is not hidden or presented as a speed improvement.

The subsequent candidate replaces that preflight with a sufficient range certificate only for score grids larger than 4,096 elements and head widths at most 1,024. Let Mq and Mk be the maximum absolute projected query/key values and d the head width. Every absolute dot-product partial sum is bounded by d*Mq*Mk. Accept the certificate only when this bound is finite and at most one quarter of the accumulator dtype's maximum. The factor-four margin is deliberately conservative relative to rounding error for these bounded widths. Half/bfloat16 use the reference's float32 accumulator bound. If the proof is unavailable, fails, or the grid is small, compute exactly the original score matmul/division and reject nonfinite scores. A failed sufficient bound never rejects an otherwise valid input by itself. Extreme-value fallback, finite disjoint vectors with an inconclusive bound, mask invariance and forecast parity are tested.

This remains checked inference, not a blanket removal of defensive validation. It can still allocate quadratic score matrices and does not promise a memory reduction. The backend is recorded from profiler operator names; a CPU SDPA operator is not evidence of a CUDA FlashAttention benchmark.

Compare actual recovered weights over the exact inherited 32 validation origins, float32, batch size one and two Torch threads. Use torch.no_grad for both runtimes. Alternate runtime order per paired call using seed 17, exclude 10 warmups per condition, retain five repeats of 200 calls per condition, and report both prepared-engine and complete bundle-predict scopes. Three fresh interpreter trials per condition measure process RSS, including imports/corpus; they do not isolate attention tensor memory. Forecast error and per-origin drift are recorded before timing. No 2024 evaluation or model promotion is allowed.

The optional standalone worker enables SDPA only with GRIDLENS_SDPA_ENABLED=1, and then runs a startup parity gate over every packaged origin before accepting jobs. Its default stays manual. Requesting an unavailable runtime fails explicitly. Existing SQLite records migrate with runtime=manual; no existing result is rewritten. The public browser preview continues to execute its existing ONNX/JavaScript path, with recorded Python comparisons shown separately on the evidence page.
